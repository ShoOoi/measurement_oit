# Beacon RSSI GUI（取得成功回数方式）

## 変更点
- 指定した N 回のスキャン「試行」ではなく，**各ビーコンについて N 回のRSSI取得が成功するまで**測定します．
- 同じビーコンの採用するRSSI測定間隔は **最低 M 秒**空けます．BLE広告の到着が遅い場合，実際の測定間隔は M 秒より長くなります．
- 台数が3台，N=30なら，各IDで30個ずつ，合計90個の成功データを取得して自動終了します．
- 受信できないIDがあると測定は完了しません．必要に応じて「中止」を押してください．中止までのデータは保存できます．
- 測定履歴は初期非表示．表示ボタンでスクロール可能な一覧を開けます．
- 履歴とCSVは，受信できたRSSIごとに1行が追加されます．他のビーコンの欄は空白です．同時刻に存在しない観測値を同じ回数として並べることを防ぐためです．

## 実行

```bash
pip install -r requirements.txt
python beacon_gui.py
```

## 注意
- `extract_id()` はBLEの広告名から6桁IDを抽出する仮の実装です．ビーコンの実際の広告フォーマットに合わせて調整してください．
- BLE機器の広告発信間隔や電波状況によって取得所要時間は変化します．
- Bluetoothが有効であり，OSのアクセス許可が適切である必要があります．
